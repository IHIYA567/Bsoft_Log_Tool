工程日志智能填充 (Log-Filler-Bsoft)
🚀 工具简介
本工具是专为 Bsoft（创业软件）系统供应商 开发的日志录入辅助插件。旨在解决在 office.bsoft.com.cn 系统中录入工程日志时，表单项繁琐、重复操作多的痛点。

通过预设逻辑与智能匹配，实现一键完成“出差状态、住宿情况、合同范围、工作计划、工时、工作内容类别”等十余项数据的填充。

✨ 核心功能
智能表单识别：基于 Ant Design 组件特征，精准定位单选框（Radio）、复选框（Checkbox）及输入框。

多维度配置映射：内置住宿、角色（技术/工程/服务等）、工作方式、任务结果等完整字典映射。

物理对齐补偿：V10.8 版本优化了设置面板的刻度对齐逻辑，确保在不同分辨率下拥有良好的 UI 体验。

持久化配置管理：支持自定义“启动延迟”与“默认工时”，配置自动保存至浏览器本地，无需重复设置。

即时反馈系统：填充完成后弹出动态反馈列表，各模块填充状态（✅/❌）一目了然。

🛠️ 安装指南
作为原生 Chrome 扩展加载
下载本项目源代码并解压。

进入 Chrome chrome://extensions/，开启开发者模式。

点击“加载已解压的扩展程序”，选中含有 manifest.json 的文件夹。

⚙️ 技术实现
语言：JavaScript (ES6+)

存储：利用 localStorage 实现轻量化配置持久化。

UI注入：通过原生 CSS 动画与高性能 DOM 操作实现非侵入式悬浮窗。

兼容性：支持主流 Chromium 内核浏览器。
