# Bsoft 日志自动填充工具 (Bsoft_Log_Tool)

🚀 **当前版本：V2.1**

## 🚀 工具简介
本工具是专为 Bsoft（创业软件）系统供应商及实施团队开发的日志录入辅助插件。旨在解决在 `office.bsoft.com.cn` 系统中录入每日工程日志时，表单项繁琐、重复操作多的痛点。

通过预设逻辑与智能匹配，实现一键秒级完成“出差状态、住宿情况、计划类型、合同范围、角色、工作方式、工作内容类别、任务结果、工时”等十余项表单数据的全自动填充。

---

## ✨ 核心功能
* **🤖 智能表单识别**：基于 Ant Design 组件特征，精准定位单选框（Radio）、复选框（Checkbox）及数字输入框，实现一键精准触达。
* **📁 多维度配置映射**：内置完整的日志字典映射，支持对住宿情况、工作计划、合同范围、人员角色、工作方式、任务类别、执行结果等进行个性化预设。
* **⚙️ 动态进入页面自启**：支持自定义 `1s - 10s` 的启动延迟。开启后，每次进入日志页面，工具将在后台自动等待网页 DOM 加载完毕并执行全自动勾选，无需手动干预。
* **📊 集中监控矩阵**：填充完成后自动唤起右侧浮动看板，实时扫描并比对当前页面实际勾选值与配置预期，同步状态（✅ 已同步 / ⚡ 差异 / ⏳ 待选择）一目了然，并在 4.5 秒后自动淡出隐藏。
* **💾 持久化配置管理**：所有配置改动即时生效，并自动保存至浏览器本地存储，下次打开页面或浏览器重启后依然保留个性化预设。

## 🛠️ 安装指南
### 作为原生 Chrome 扩展加载
1.  下载本项目源代码并解压（确保包含 `manifest.json`、`content.js` 等文件）。
2.  打开 Chrome 浏览器，访问 `chrome://extensions/` 页面。
3.  在右上方开启 **“开发者模式”**（Developer mode）。
4.  点击左上角 **“加载已解压的扩展程序”**（Load unpacked），选中含有 `manifest.json` 的文件夹即可完成安装。

## ⚙️ 技术实现
* **语言**：纯原生 JavaScript (ES6+)
* **存储**：利用 `chrome.storage.local` 高效实现多配置项、高隔离性的持久化存储，改动即时生效。
* **UI 注入**：基于原生 CSS `@keyframes` 动画与高性能 DOM 渲染，构建非侵入式的悬浮窗与状态监控面板，不破坏原本页面的样式与布局。
* **兼容性**：完美支持主流 Chromium 内核浏览器（Chrome、Edge、百分浏览器等）。
