# Bsoft 日志自动填充工具 (Bsoft_Log_Tool)

🚀 **当前版本：V2.3.1**

## 工具简介
一款用于日常工程日志录入的浏览器辅助扩展。把反复点选的十余项表单项——出差状态、住宿情况、计划类型、合同范围、角色、工作方式、工作内容类别、任务结果、工时等——做成可配置预设，一键完成填充。

> ⚠️ 新版日志页把表单放进了隔离容器，旧版脚本无法命中，会出现全部「⚡ 差异」。V2.2 起已适配，并同时兼容旧版页面。

## ✨ 核心功能
* **🤖 智能表单识别**：按表单组件特征定位单选框、复选框与数字输入框。
* **🧩 隔离容器穿透**：自动收集所有可查询的文档根；表单异步挂载时自动等待，填充后多轮校验并自动补填，避免重渲染延迟造成误报。
* **📁 多维度配置映射**：住宿、计划、合同范围、角色、方式、类别、结果等均可个性化预设。
* **⚙️ 进入页面自启**：可设置 1–10 秒启动延迟，进入日志页后自动执行。
* **📊 集中监控矩阵**：约 120ms 弹出右侧看板，显示 ✅ 已同步 / ⚡ 差异 / ⏳ 校验中 / ⏭ 项目无此选项 / ⚠️ 未找到控件；校验结果就地刷新，3 秒自动淡出，底部红色按钮可立即关闭。
* **⚡ 设置即时联动**：在设置面板改选项，页面表单同步变化；项目不提供该选项或选项被禁用时明确跳过并提示，不再反复重试或残留红框。
* **💾 持久化配置**：配置保存在浏览器本地存储，重启浏览器后依然保留。
* **📋 一键诊断导出**：导出技术诊断日志（容器、字段命中、重试、校验轮次），便于排查；不采集业务数据。

## 🛠️ 安装指南
1. 下载发行版压缩包并解压。
2. 打开 `chrome://extensions/`（Edge 为 `edge://extensions/`）。
3. 开启右上角 **开发者模式** / **开发人员模式**。
4. 点击 **加载已解压的扩展程序**，选择含 `manifest.json` 的文件夹。
5. 修改过代码后，需在扩展管理页点击 **刷新** 才会生效。

> 扩展只在清单中声明的目标站点注入，其它页面不会加载。

## ⚙️ 技术实现
* 纯原生 JavaScript (ES6+)，无构建步骤、无第三方依赖。
* 使用 `chrome.storage.local` 持久化配置。
* 原生 CSS 动画与 DOM 渲染构建非侵入式浮层，不改动原页面样式与布局。
* 支持主流 Chromium 内核浏览器（Chrome、Edge、百分浏览器等）。
